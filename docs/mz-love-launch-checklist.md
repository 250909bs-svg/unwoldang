# MZ무당 팩폭 연애운 — 출시 체크리스트

이 문서는 출시 직전 실제 환경에서 확인할 항목이다. 자동 테스트 통과 수는 이 문서에 고정하지 않고, 실행한 빌드나 CI 기록에서 확인한다.

## 상품 진입과 입력

- [ ] 홈·검색·마이페이지·내비게이션이 `/detail/love-reading`으로 연결됨
- [ ] 티저 ACT 00–10과 연애 반응 `A | B | C | D` 선택이 동작함
- [ ] 선택값이 새로고침과 입력·분석 이동 뒤에도 유지됨
- [ ] CTA가 `/form/love-reading`으로 이동함
- [ ] 관계 상태가 솔로·썸·연애 중·애매함·이별/재회·기혼의 정확히 6종으로 표시됨
- [ ] 연애 중과 기혼에서 관계 기간이 필수이고 나머지 상태에서는 선택임
- [ ] 기혼 입력이 장기 관계 리포트 분기로 변환됨
- [ ] 기존 Checkout → Loading → Report 흐름이 유지됨

## 리포트 기능

- [ ] 13개 결과 챕터와 목차 앵커가 모두 동작함
- [ ] 각 챕터가 팩폭·명리 해석·현실 장면·반대 가능성·확인 기준·행동을 표시함
- [ ] 설렘/지속 가능성 비교 탭이 키보드와 터치로 동작함
- [ ] 12개월 탭이 실제 월운 12개를 표시함
- [ ] 메시지 선택과 정적 대체 해설이 동작함
- [ ] 실제 리포트의 레드 플래그·그린 플래그가 표시됨
- [ ] 30일 체크리스트가 저장되고 다시 열었을 때 복원됨

## 명리 근거와 문장 안전

- [ ] 원국·오행·십성·합충·대운·세운 근거가 계산 결과와 일치함
- [ ] 고객 해석에 연결된 모든 근거가 같은 원문 `sourcePath`에서 왔음
- [ ] 출처가 없는 해석에 다른 종류의 근거가 임의로 채워지지 않음
- [ ] 근거 상세에 라벨·값·설명·출처와 선택적 신뢰도가 보임
- [ ] 결정론적 근거 원문이 바이트 단위로 변형되지 않음
- [ ] 엔진 ID·감사 로그·내부 계산 문장이 캐릭터 대사로 노출되지 않음
- [ ] 근거 없는 상대 속마음 단정이 없음
- [ ] 결혼·재회·연락 날짜를 확정하지 않음
- [ ] 시간 미상 또는 경계 입력의 불확실성을 표시함
- [ ] 핵심 판정에 반대 가능성과 현실 확인 행동이 함께 있음
- [ ] 질병·법률·투자 결정을 대신하는 표현이 없음
- [ ] 가짜 후기·판매량·순위 문구가 없음

## 이미지 자산과 장면 선택

- [ ] `artwork-source/mz-love-fact`에 소스 PNG가 정확히 30장 있음
- [ ] `public/images/mz-love-fact/generated`에 WebP 30장과 AVIF 30장이 있음
- [ ] 최적화본 60개가 모두 1080×1920이고 파일 크기가 0보다 큼
- [ ] 30개 키가 `sceneManifest.ts`와 파일명에 일대일 대응함
- [ ] 매니페스트의 대체 텍스트와 초점 좌표가 모든 장면에 있음
- [ ] 관계 상태와 의미 신호를 바꿨을 때 의도한 장면 후보가 선택됨
- [ ] 한 결과의 13개 챕터 장면이 서로 중복되지 않음
- [ ] 얼굴·손·장신구·부채 불량이 없음
- [ ] 생성 글자·로고·워터마크·과한 노출·공포 표현이 없음
- [ ] 첫 화면 외 이미지는 lazy 로딩되고 AVIF 실패 시 WebP가 표시됨

## 접근 제어와 서버 권한

- [ ] 개발 모드의 루프백 호스트에서만 결제 없는 샘플 리포트가 열림
- [ ] 운영 호스트에서 주문 정보 없이 `/report/love-reading` 직접 접근 시 잠김
- [ ] 유효한 주문 ID, 구조가 올바른 리포트, 일치하는 서비스 ID가 있어야 렌더링됨
- [ ] 클라이언트 잠금과 별개로 서버가 결제 확인·리포트 발급·원격 보관 쓰기를 최종 검증함
- [ ] 결제 성공·실패·취소·재시도 흐름이 각각 올바르게 끝남
- [ ] 인증 토큰과 리포트 접근 토큰 없이 원격 보관 요청을 보내지 않음
- [ ] Supabase RLS와 리포트 소유권이 다른 사용자 접근을 차단함

## HTML 보관과 공유

- [ ] HTML 저장본이 체크박스의 현재 완료 상태를 보존함
- [ ] HTML 저장본에서 근거 상세, 두 비교 패널, 12개월 패널이 모두 보임
- [ ] 메시지 상호작용 대신 모든 선택의 정적 해설이 포함됨
- [ ] 저장본에서 고정 CTA·조작 버튼·상태 메시지가 제거됨
- [ ] 저장본의 이미지가 외부 런타임 상태 없이 표시됨
- [ ] HTML 다운로드·바로 보기·브라우저 인쇄가 모바일과 데스크톱에서 동작함
- [ ] 연애운 공유가 `/detail/love-reading` 상품 링크만 전달함
- [ ] 공유 데이터에 이름·생년월일·관계 상태·개인 판정·주문 ID·토큰이 없음
