# MZ큐피트 재회운 계산 정책

> 현재 룰 버전: `reunion-policy-2026.07`
> 현재 리포트 버전: `reunion-report-v1.0.0`

## 1. 해석 원칙

재회운은 미래 사건의 확률 계산기가 아니라 **연락·대기·비접촉 선택을 비교하기 위한 의사결정 보조 도구**다.

- 재회, 연락, 답장, 만남을 보장하지 않는다.
- 상대의 속마음이나 현재 연애 상태를 명리로 확정하지 않는다.
- 특정 연락 날짜를 “정답”으로 제시하지 않는다.
- 사용자가 입력한 사실과 관찰 가능한 행동을 명리 신호보다 우선한다.
- 안전과 명시적 경계는 모든 점수보다 우선한다.
- 동일 지표에 지지 근거와 반대 근거를 함께 제공한다.

## 2. 입력과 출처

| 입력군 | 예시 | 해석 범위 |
| --- | --- | --- |
| 본인 출생정보 | 생년월일, 시각, 달력, 성별, 위치 | 절기 만세력·명리 계산 |
| 상대 출생정보 | 알려진 범위와 정확도 | 제공된 경우에만 상대 원국·정적 궁합 보조 |
| 관계 사실 | 교제·이별·마지막 연락, 이별 원인, 차단, 반복 재회 | 사용자 진술로 취급 |
| 행동·준비도 | 책임 인정, 원인 변화, 무응답 수용, 경계 존중 | 실행 가능성 판단 |
| 안전 신호 | 거부, 차단 우회, 폭력, 위협, 통제, 스토킹 등 | SafetyGate 최우선 판단 |
| 질문 | 연락, 재회, 재발, 장기 지속 등 최대 선택 질문 | 첫 화면 답변 순서 |

사용자 진술은 상대의 내면이나 객관적 사실로 승격하지 않는다. 대리 입력은 신뢰도를 낮추며, 정보 사용 권한을 확인하지 못하면 분석을 시작하지 않는다.

## 3. 계산 구성요소 상태

| 구성요소 | 상태 | 점수 사용 |
| --- | --- | --- |
| 절기 만세력·명리 | 내부 규칙·회귀 검증 완료, 외부 명리 전문가 감수 전 | 사용 |
| 정적 두 사람 궁합 | 상대 출생정보가 있을 때 기존 v2 엔진 사용 | 제한 사용 |
| 대운·세운 완전 동시 교차 | 미완성 | 완전 구현으로 주장하지 않음 |
| 월운 구간 | 절기 단위 넓은 구간 | 조건부 보조 |
| 일진·특정 연락일 추천 | 미구현 | 미사용 |
| 자미두수 | `UNVERIFIED`, 엔진·골든 fixture 없음 | 미사용 |
| 관계 사실·행동 | 사용자 입력 | 사용 |
| SafetyGate | 정책 강제 | 항상 최우선 |

## 4. 14개 지표

모든 값은 0~100 범위의 **비교 지수**이며 사건 발생 확률이나 통계적 예측 확률이 아니다.

1. 감정 잔여 지수
2. 상대 선연락 신호 지수
3. 내가 연락할 적합 지수
4. 답장 전환 지수
5. 만남 전환 지수
6. 관계 재정의 지수
7. 재회 지수
8. 재회 후 30일 유지 지수
9. 재회 후 90일 유지 지수
10. 장기 지속 지수
11. 같은 이유 재발 위험 지수
12. 연락 피해 위험 지수
13. 현실 장벽 지수
14. 재회 준비도

재발 위험, 연락 피해 위험, 현실 장벽은 높을수록 불리한 **위험 지수**다. 나머지 지수와 같은 방향으로 읽으면 안 된다.

각 지표는 다음 필드를 가진다.

- 상태: `AVAILABLE`, `WITHHELD_SAFETY`, `INSUFFICIENT_DATA`
- 점수 또는 보류값
- 구간 라벨
- 지지 근거 ID와 반대 근거 ID
- 현실 확인 항목
- 실행 항목과 금지 항목
- 결과를 바꿀 수 있는 조건

현재 고정 가중식과 clamp 규칙의 단일 진실 원천은 `src/lib/reunion/scoring.ts`다. 문구 작성 계층이나 LLM이 이 값을 다시 계산하거나 덮어쓰면 안 된다.

## 5. EvidenceGraph 정책

근거 출처는 다음 다섯 종류로 제한한다.

- `SAJU`: 계산된 명리 구조
- `RELATIONSHIP_FACT`: 사용자가 입력한 관계 사실
- `BEHAVIOR`: 관찰 가능 행동과 준비도
- `SAFETY`: 경계·위험 정책
- `SYSTEM_LIMIT`: 미상 시각, 미제공 상대 정보, 미구현 엔진 같은 한계

모든 지표 참조 ID는 실제 EvidenceGraph 노드에 존재해야 한다. 근거가 없으면 값을 만들어내지 않고 `INSUFFICIENT_DATA` 또는 명시적 한계를 사용한다.

## 6. SafetyGate와 계산 순서

SafetyGate는 명리·궁합·시기 계산 결과보다 먼저 적용한다.

| 상태 | 계산·표시 정책 |
| --- | --- |
| `ANALYSIS_BLOCKED` | 위험 또는 필수 동의 누락. 연락 시기·문구·응답 전략 미제공 |
| `CONTACT_PROHIBITED` | 명시적 거부·차단·경계 침해 등. 연락 시기와 문구 미제공, 관련 점수 보류 |
| `PREPARATION_REQUIRED` | 원인 변화·책임·무응답 수용이 부족. 지금 연락 대신 준비 계획 제공 |
| `CONTACT_ELIGIBLE` | 모든 경계 조건을 통과했을 때만 조건부 연락 검토 |

유리한 명리 신호가 있어도 SafetyGate 결과를 완화하거나 무시할 수 없다.

## 7. 연락 구간 정책

연락 구간은 SafetyGate가 `timingAllowed=true`일 때만 최대 3개를 만든다.

- 본인과 상대 월운이 모두 있으면 현재 구현은 본인 55%, 상대 45%의 비교값을 사용한다.
- 상대 월운이 없으면 본인 월운 점수에 0.72를 적용한 제한값을 사용한다.
- 내부 비교값 52 미만 구간은 후보에서 제외한다.
- 높은 값 순으로 최대 3개만 표시한다.
- 날짜가 아니라 절기 기반 월 구간이며, 구간 점수도 연락 성공 확률이 아니다.
- 거부·차단·위험 신호가 새로 확인되면 모든 구간은 즉시 무효다.

일진 엔진이 없으므로 “정확한 연락일” 또는 “이날 연락하면 답장” 같은 표현을 금지한다.

## 8. 신뢰도 정책

리포트 신뢰도는 이벤트 적중 확률이 아니라 **입력 완전성과 현재 엔진이 해당 판단을 지지하는 정도**다.

현재 구현은 상대 출생정보 유무를 기준으로 시작값을 달리하고 다음 조건에서 낮춘다.

- 본인 또는 상대 출생시간 미상
- 상대 출생정보 미제공
- 출생정보가 근사값 또는 미상
- 본인이 아닌 대리 입력
- 미구현 자미두수와 외부 전문가 감수 전 상태

최댓값은 0.79로 제한되어 있다. 외부 전문가 감수 전 상태에서 “완전 검증”, “100% 정확”으로 표현하지 않는다.

## 9. AI 사용 정책

현재 재회운 도메인 결과는 결정론 코드가 생성한다. Gemini 등 생성 모델을 추가할 때는 다음을 강제한다.

1. 출생 변환, 사주 원국, SafetyGate, EvidenceGraph, 14개 지표, 연락 구간을 계산하지 않는다.
2. 서버가 고정한 fact ID와 수치만 참조한다.
3. 상대의 감정·의도·새 연인을 추론해 사실처럼 쓰지 않는다.
4. 보장, 공포 자극, 집착 유도, 차단 우회, 과도한 결제 유도 문구를 생성하지 않는다.
5. 문장화 뒤 fact guard와 금지 문구 QA를 다시 통과한다.
6. 실패하면 결정론 원문으로 되돌린다.

## 10. 재현성과 버전 관리

감사 가능한 결과에는 다음을 함께 저장해야 한다.

- 정규화 입력의 해시
- 분석 기준일과 생성 시각
- 리포트 버전과 룰 버전
- 만세력 엔진 버전과 정밀도
- SafetyGate 상태와 reason code
- EvidenceGraph와 14개 지표
- QA 결과

현재 프런트엔드 계산을 서버 권위 계산으로 이전하고, 모든 하위 시간 계산에 동일한 명시적 기준 시각을 전달해야 완전한 재현성을 주장할 수 있다.

## 11. 현재 QA

런타임 감사는 다음을 검사한다.

- 안전 제한 시 연락 구간이 비어 있는지
- 분리 지표가 최소 13개인지(현재 실제 생성은 14개)
- 모든 근거 참조가 EvidenceGraph에 존재하는지
- 모든 지표에 지지·반대 근거가 있는지
- 자미두수가 `UNVERIFIED`이고 점수에서 제외되는지
- “100% 재회”, “무조건 재회”, “반드시 연락”, 상대 감정 확정, 정확한 연락일 같은 금지 단정이 없는지

단위 테스트는 14개 지표 생성, 안전 우선, 미상 상대 정보의 신뢰도 하향, 동일 입력 재현성, 자미두수 제외를 확인한다. 이는 외부 명리 감수, 임상적 안전 검증, 운영 보안 심사를 대체하지 않는다.
